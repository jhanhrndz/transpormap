# ADR 002 — Backend modular

**Estado:** dirección monolito modular Spring Boot y detalle aprobados, con viabilidad pendiente. **Contexto:** Spring Boot obligatorio y recursos de una persona. **Opciones:** monolito modular; microservicios; Maven o Gradle para build. **Dirección:** monolito modular por despliegue y transacciones simples. El esqueleto usa Maven Wrapper, Java 25 y Spring Boot 4.1.2; su compatibilidad con hosting sigue pendiente. El checksum del wrapper se verificó con cachés nuevas, sin verificar firma PGP. **Consecuencias:** menor complejidad operativa, pero fallos afectan al proceso completo y el uso de memoria/arranque debe medirse. Se conserva trazabilidad de módulos Swing/DAO al dominio actual. [Detalle](../06-arquitectura-detallada-backend.md).
