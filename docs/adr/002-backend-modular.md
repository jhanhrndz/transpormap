# ADR 002 — Backend modular

**Estado:** dirección monolito modular Spring Boot aprobada; detalles y viabilidad pendientes. **Contexto:** Spring Boot obligatorio y recursos de una persona. **Opciones:** monolito modular; microservicios; Maven o Gradle para build. **Dirección:** monolito modular por despliegue y transacciones simples. El esqueleto usa Maven Wrapper, Java 25 y Spring Boot 4.1.2; su compatibilidad con hosting y checksum del wrapper siguen pendientes. **Consecuencias:** menor complejidad operativa, pero fallos afectan al proceso completo y el uso de memoria/arranque debe medirse. Se conserva trazabilidad de módulos Swing/DAO al dominio actual. [Detalle propuesto](../06-arquitectura-detallada-backend.md).
